# Lumi (macOS Native)

Birden çok Claude Code CLI instance'ını yöneten desktop dashboard'un macOS-native (Swift) rewrite'ı. Electron sürümünün (`../ai-orchestrator`) yerini alacak.

## Durum

Keşif, tasarım ve implementasyonun 6 fazı (`docs/design/04-prototype-plan.md`) ve ardından 2026-09-04/05 sağlamlaştırma refactor'unun 7 fazı (`docs/refactor-plan-2026-09.md` — acil fix'ler, test güvenlik ağı, DI/composition root, terminal sınırları, state ayrışması, generic shell, LumiUI bileşen kütüphanesi) tamamlandı; **1299 test yeşil**. Personas + Quick Actions ve terminal tema seçimi 2026-09-04'te kaldırıldı (karar 25–26); header düzeltmeleri karar 27; file-tree tarama güvenliği (bellek sızıntısı düzeltmesi) karar 28; max terminal limiti + font smoothing ayarı kaldırıldı karar 29; 36px ince top bar + doğal traffic light konumu karar 30; ince kart header'ı + grid default'u 1 kolon/Fit karar 31; Claude+Codex kullanım göstergeleri (Orca'nın eriştiği yollardan — Claude OAuth endpoint'i, Codex app-server RPC) karar 32. Sağ proje paneli 2026-09-05'te Explorer / Agent History / koşullu Source Control sekmelerine geçti; eski Project Context ve Git panel kayıtları kaldırıldı, Unity Assets modu ve gerçek Claude/Codex oturum geçmişi eklendi (karar 39). Refactor kararları: kabuk artık slot/route/toolbar/overlay descriptor registry'leriyle kurulur (karar 33); `ui-state.json`'a additive `activeRoute`/`panelLayout`/`visibleSlots` anahtarları eklendi, eski sidebar bool'ları projeksiyon olarak yazılmaya devam eder (karar 34); `WorkspaceStore` facade'ı `NavigationStore`+`LayoutStore`+`DialogRouter`'a bölündü, route ve FileViewer sunumu sum type oldu (karar 35); composition root `ServiceRegistry` + `FeatureAssembly`/`BootstrapPhase` + tek kaynaklı `AppCommand` üzerine oturdu (karar 36); terminalde `TerminalSurfaceState` görünürlük+odağı tek kanala indirdi, `FeedWatchdog` ve enjekte edilen `OSCSemantics` zinciri eklendi (karar 37); kullanım göstergesi aralıkları {5,15,30} + 300 sn TTL cache ve Claude OAuth hata politikası netleşti (karar 38). Source Control History tek `git log HEAD --topo-order` graph'ı + `gh pr create --web` (karar 40); Orca parite düzeltmeleri — branch özeti başlığı, regex/glob içerik araması, custom popover menüler, Unity otomatik Assets görünümü, alt ajanlı Agent History kartı (karar 41). Kod `LumiPackages/` altında (modüller: LumiKit/LumiTerminal/LumiServices/LumiState/LumiUI + LumiAppCore library + ince LumiApp executable + LumiTestSupport paylaşılan fake target'ı). Geliştirme: `cd LumiPackages && swift run Lumi`; paketleme: `Scripts/make-app.sh` (imza: `IDENTITY` → keychain'deki Apple Development sertifikası → ad-hoc; `--install` ile `/Applications`'a kurar; `IDENTITY=... Teknoloji kararları (2026-06-11, bağlayıcı — detay ve gerekçeler `docs/design/00-architecture.md`):
- **SwiftTerm** (SPM) + oturum başına kalıcı view-attached emülatör; PTY katmanı kendi `PTYProcess` wrapper'ımız (LocalProcess değil)
- **AppKit kabuk + SwiftUI içerik**; terminal NSView'ları SwiftUI dışında `TerminalViewRegistry`'de
- **Manuel DI + `AppContainer` composition root**; lokal SPM paketleri `LumiKit ← LumiTerminal / LumiServices / LumiState ← LumiUI`
- **macOS 14+**, Swift 6 strict concurrency; servis→store `AsyncStream`, store→UI `@Observable`, Combine yok

## Kurallar

- **Davranışın kaynağı implementasyonun kendisidir:** Rewrite tamamlandığı için Electron davranış envanteri spec'leri (`docs/spec/`) 2026-09-04'te kaldırıldı (git history'de duruyor; Electron kodu da `../ai-orchestrator`'da yerinde). Yeni iş, `LumiPackages/` altındaki kod + testlerden ve aşağıdaki iki bağlayıcı kayıttan yazılır.
- **`docs/design/` bağlayıcı tasarım kaydıdır:** Mimarinin ve implementasyon şeklinin kaynağı. Tasarımla çelişen implementasyon yapma; tasarım değişikliği gerekiyorsa önce kullanıcıya sor ve ilgili design dosyasını güncelle.
- **`docs/decisions.md` bağlayıcı karar kaydıdır:** Kapsam, atılan özellikler ve bilinçli davranış değişiklikleri burada. Bu kararlarla çelişen bir implementasyon yapma; karar değişikliği gerekiyorsa önce kullanıcıya sor ve dosyayı güncelle.
- **Zorunlu mimari gereksinimler** (`docs/design/00-architecture.md` Ek A): PTY→UI ack-tabanlı backpressure, render-crash izolasyonu, replay güvenliği (sequence-güvenli kesim, terminal otomatik yanıt filtresi). Bunlar sonradan eklenemez — çekirdek tasarımın parçası.
- **SOLID + dependency injection:** Rewrite'ın ana hedeflerinden biri; view katmanı iş mantığından ayrı tutulur.
- **Persistence uyumluluğu:** `~/.lumi` altındaki mevcut JSON/YAML formatları aynen okunur/yazılır (karar 9) — format değişikliği yapma. Config tipleri `Codable` **değildir**; okuma/yazma yalnız `LumiServices/Config/` altındaki `ConfigCodec` bölüm codec'lerinden geçer.
- **Generic shell (karar 33):** Yeni bir görünüm, panel öğesi veya toolbar öğesi `RootView`/`PanelHostView`/`HeaderBarView`/`ContentRouterView`'a **dokunmadan** eklenir: bir `FeatureAssembly` (+ katkı veriyorsa `ShellContributing`) yazılır, descriptor'lar `ShellRegistries`'e kaydedilir ve `AppComposition`'daki assembly listesine tek satır eklenir. `AnyView` yalnız descriptor'ın `makeView`'ında kullanılır.
- **LumiUI'da literal yok:** Font boyutu ve köşe yarıçapı literal olarak yazılmaz; `Theme.Typography` / `Theme.Radius` / `Theme.Spacing` / `Theme.Motion` token'ları zorunludur (`DesignTokenLintTests` bütçeyi sıfırda kilitler). Her `#Preview` `#if DEBUG` içinde olmalıdır (`PreviewGuardLintTests`).
- **Yeni servis eklerken:** process I/O `ProcessRunning` (+ `BinaryLocating`) enjeksiyonundan geçer, fake'i `LumiTestSupport`'a eklenir ve `LiveServiceRegistry`/`FakeServiceRegistry`'ye bir satırla bağlanır.
- **Geliştirme komutları** (CI üçünü de koşar): `cd LumiPackages && swift build`, `swift test`, `swift build -c release --product Lumi`.
